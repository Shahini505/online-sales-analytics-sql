# Online Sales Analytics using SQL

## 📌 Project Overview
This project focuses on analyzing an online sales database using SQL to extract actionable business insights.

The database is designed using a normalized relational schema consisting of customers, products, orders, and order items. SQL queries are used to analyze revenue trends, customer behavior, and product performance.

This project simulates a real-world business analytics use case commonly encountered in data analyst and software engineering roles.

---

## 🎯 Objectives
- Analyze sales performance using SQL
- Identify high-revenue products and categories
- Understand customer purchasing patterns
- Practice real-world SQL querying techniques

---

## 🛠 Tools & Technologies
- MySQL  
- MySQL Workbench  
- SQL  

---

## 📊 Key Insights
- Computed total and category-wise sales revenue
- Identified top-selling products based on revenue
- Analyzed customer order frequency
- Detected products that were never purchased
- Extracted business-driven insights using SQL joins and aggregations

---

## 🧠 SQL Concepts Demonstrated
- Data retrieval using `SELECT` and `WHERE`
- Table relationships using `INNER JOIN` and `LEFT JOIN`
- Aggregation using `SUM`, `COUNT`, and `AVG`
- Group-based filtering using `GROUP BY` and `HAVING`
- Subqueries for advanced data analysis
- Business-oriented data analysis mindset
